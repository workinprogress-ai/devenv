# Copilot Skills Catalog

The full skill reference — decision tree, per-skill descriptions, and the quick-reference tables — lives in one place: [Skills](../../_shared/docs/Skills.md) (`docs/Skills.md`).

Routing (which skill fits an intent, and chains of skills) is maintained in the [skills registry](../../devenv-help/references/skills-registry.md); `/devenv-help` reads it.

**Not sure which skill to use, or how something in this environment works?** Say `/devenv-help`.
