# Copilot Skills Catalog

The full skill reference — decision tree, per-skill descriptions, and the quick-reference tables — lives in one place: [Skills](../../_shared/docs/Skills.md) (`docs/Skills.md`).

Routing (which skill fits an intent, and chains of skills) is maintained in the [skills registry](../../devenv-help/references/skills-registry.md); `/devenv-help` reads it.

**Not sure which skill to use, how something in this environment works, or how you should be working (sessions, modes, review setup)?** Say `/devenv-help` — it answers, recommends, and advises.

Moving from one skill to another — in the same session or in a new one — follows the [Skill Handoff Protocol](./skill-handoff-protocol.md): facts and artifact references carry over, a prior skill's conclusions and consent never do.
